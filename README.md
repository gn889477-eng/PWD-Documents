# PWD Documents - Android App

A simple Android app that displays document information for the PWD (PDF Words Documentos) format.

## What is included

- Android Studio project structure
- Minimal app UI
- Main activity with text output
- Gradle configuration

## Build locally

1. Open this repo in Android Studio.
2. Let Gradle sync.
3. Choose Build > Build Bundle(s) / APK(s) > Build APK(s).
4. The APK will be generated in `app/build/outputs/apk/debug/`.

## APK location after build

`app/build/outputs/apk/debug/app-debug.apk`

## Notes

This project is a simple demo and not a full PDF viewer. It is meant as a starter project for PWD document branding and UI.
